# ecomm backend — Python (FastAPI) port

A 1:1 conversion of the original Node/Express + Mongoose backend
(`Manime016/ecomm/backend`) to Python, using **FastAPI** + **Motor**
(async MongoDB driver). Folder layout mirrors the original:

```
config/       -> db.py, cloudinary_config.py, razorpay_config.py
models/       -> user.py, product.py, cart.py, order.py, coupon.py
controller/   -> auth/user/product/cart/order/coupon controllers
middleware/   -> auth_middleware (protect), admin_middleware (isAdmin), error_middleware
routes/       -> one APIRouter per resource, mounted under the same /api/* prefixes
utils/        -> security.py (bcrypt+JWT), serializers.py, errors.py
server.py     -> app entrypoint (equivalent of server.js)
```

## Setup

```bash
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env            # fill in MONGO_URI, JWT_SECRET, Cloudinary, Razorpay keys
```

## Run

```bash
uvicorn server:app --reload --port 5000
# or: python server.py
```

Interactive API docs (auto-generated by FastAPI) are then available at
`http://localhost:5000/docs`.

## Route map (unchanged from the Node version)

| Prefix | Router |
|---|---|
| `/api/auth` | register, login, forgot |
| `/api/products` | CRUD + recent-search |
| `/api/cart` | get/add/update/remove/clear |
| `/api/orders` | razorpay create/verify, create/list/get/cancel, admin status update |
| `/api/coupons` | list, apply |
| `/api/users` | profile, send-otp, update-profile |

## Notable behavior differences / fixes from the original

- **`POST /api/products/recent-search`**: the original Express route never
  attached the `protect` middleware even though the controller reads
  `req.user`, which would crash. This port requires auth on that route so it
  actually works.
- **`GET /api/coupons`**: the original Mongoose query object had two `$or`
  keys in the same object literal — in JavaScript the second one silently
  wins. This port keeps that same effective query for parity, filtering only
  on `validTill`. Flag this if you'd rather combine both conditions with
  `$and`.
- Password hashing uses `bcrypt` directly (same algorithm as `bcryptjs`,
  cost factor 10). JWTs use `PyJWT` with the same `HS256`/1-day-expiry shape.
- File uploads: `multer.memoryStorage()` + Cloudinary base64 upload is
  replicated with FastAPI's `UploadFile` + the `cloudinary` Python SDK,
  including the 2MB size cap.
- Error responses keep the same JSON shape as the Express `errorHandler`
  (`{"message": ..., "stack": ...}`), including 404 "Resource not found" for
  bad ObjectIds and 400 "Duplicate field value entered" for unique-index
  violations.
- Mongoose's schema-level indexes (`unique: true`, text index, compound
  index) are recreated with `create_indexes()`, called once on startup.

## Not carried over

The original `package.json` lists `socket.io` and `nodemailer` as
dependencies, but neither is actually wired into any controller/route in
this backend — so no Python equivalent was added. Add `python-socketio` /
an SMTP client if/when you actually use them.
